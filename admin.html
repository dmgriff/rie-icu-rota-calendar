Minimal workflow

  1. Create the official ICU rota as a Word .docx file.
  2. Open the GitHub repository.
  3. Open the rotas folder.
  4. Upload the new Word rota file into that folder.
  5. Commit changes.
  6. The public webpage will automatically find the new file and add its date range to the dropdown.

Important

Do not delete previous Word rota files unless you want to remove those periods from the dropdown.

If a new file overlaps an old file, the app uses the newest uploaded file for the overlapping month.

Only people with GitHub write access can upload or delete rota files.
